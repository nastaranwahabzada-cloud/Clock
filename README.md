
# ORBITAL — Luxury Solar System Clock

پروژه‌ی تک‌صفحه‌ای ساعت دیجیتال لوکس با منظومه شمسی متحرک.

## قابلیت‌ها
- ساعت زنده با فرمت ۱۲ و ۲۴ ساعته
- نمایش ثانیه و تاریخ شمسی یا میلادی
- انتخاب منطقه‌ی زمانی
- تم روشن و تاریک و حالت تمام‌صفحه
- انیمیشن مداری خورشید و هشت سیاره
- پنجره‌ی معرفی شیک و متحرک با کلیک روی هر سیاره
- بستن پنجره با دکمه، کلیک روی پس‌زمینه یا کلید Escape
- طراحی واکنش‌گرا برای موبایل و دسکتاپ

## اجرا
فایل `index.html` را در مرورگر باز کنید. برای نمایش فونت آنلاین، اینترنت لازم است.
هیچ فریم‌ورک یا کتابخانه‌ی JavaScript خارجی برای اجرای ساعت نیاز نیست.

## ساختار
- `index.html` — ساختار صفحه
- `style.css` — استایل‌ها، طراحی واکنش‌گرا و انیمیشن‌ها
- `script.js` — ساعت، تنظیمات و تعامل سیاره‌ها
